# Placeholder media — not final

Everything in this folder came from the design concept in
`design_handoff/homepage-concept/uploads/`, downscaled and re-encoded for the web
(13MB → ~1.1MB). It exists so the homepage renders for review.

**None of it is approved production photography.** Brief §11 requires Radix to supply:

- Fresh professional shots of every current product on a clean background
- Current factory floor, machinery and QC lab photos, plus a walkthrough video
- Real team and leadership photos
- Updated brand marks if the logo has changed
- Current packaging / casing artwork

Replace these files as real assets arrive, then delete this README. Until then, treat
every image here as temporary and do not reference them from anything that ships to
production without checking with the project owner first.

The two videos in `public/video/` are also from the concept and carry the same caveat.
They are uncompressed relative to what production wants — no `ffmpeg` was available when
they were imported, so re-encoding to a web profile is still outstanding (Phase 6).
